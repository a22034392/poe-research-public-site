POE研究所中文公開版－隱私政策

最後更新：2026-10-02

發布者：POE研究所

1. 本工具處理哪些資料

POE研究所中文公開版用於 Path of Exile 1 Build 健檢與 PoB 分析。 使用者可能主動提供 PoB Code、PoB XML、角色配置、裝備、技能、 珠寶、天賦、守衛、幽魂、傭兵與其他與 Build 分析相關的資料。

本工具不要求使用者提供付款卡資料、政府身分證號、密碼、 API 金鑰、驗證碼或其他與 Build 健檢無關的敏感憑證。

2. 資料使用目的

使用者提供的資料僅用於完成當次請求，例如解析 PoB、 辨識目前使用中的配置、分析傷害與防禦互動、 說明證據與未知項目，以及提供 Build 改善方向。

3. 資料分享與第三方

本外掛本身不經營獨立的使用者資料庫，也不會出售使用者資料。 不會為了 Build 健檢而主動將完整 PoB、角色資料或個人資料 提供給廣告商或其他無關第三方。

分析過程可能透過 ChatGPT 所提供的工具查詢公開的 Path of Exile 遊戲資料，例如 Path of Exile 官方資料、PoEDB、poe.ninja 或其他 PoE1 公開來源。查詢應限於完成分析所需的遊戲機制、 版本與公開資料，並避免傳送不必要的個人資料。

ChatGPT／OpenAI 平台本身對對話、檔案與服務資料的處理， 依 OpenAI 自身的隱私政策與使用者資料控制設定辦理。 本政策主要說明 POE研究所中文公開版自身的資料使用行為。

4. 資料保存期間

POE研究所中文公開版本身不會將使用者的 Build、PoB、 角色資料或健檢結果自動永久保存到獨立資料庫、 中央知識庫或私人研究資料庫。

本外掛不另外設定獨立的長期保存期限。 對話與上傳檔案若由 ChatGPT／OpenAI 平台保存， 其保存期間及刪除方式依 OpenAI 的資料控制與相關政策為準。

5. 使用者控制

使用者可以選擇不提供非必要資料，例如守衛裝備、 幽魂種類、傭兵技能或其他額外角色資訊。 若資料不足，本工具應將結果標示為未知或未驗證， 而不是自行補造。

使用者可透過 ChatGPT 提供的對話及資料控制功能， 管理或刪除其在 ChatGPT 中的對話與相關資料。

6. 自動入庫與研究資料

公開版收到的 Build 與 PoB 預設只供當次分析使用。 本工具不會自行將使用者資料升格為研究資料、 建立 ACTIVE 紀錄、加入私人 Build 索引， 或寫入 POE研究所的私人中央知識庫。

7. PoB 數值與計算限制

若沒有可驗證的 PoB 計算環境，本工具不會宣稱已重新計算 DPS、EHP 或其他 PoB 數值。 PoB 中原本保存的數值會與真正重新計算的結果分開標示。

8. 聯絡方式

如有隱私政策或資料使用相關問題，可透過本專案的公開 GitHub repository 聯絡： POE研究所中文公開版 GitHub
