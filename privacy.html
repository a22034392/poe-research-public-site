POE研究所中文公開版－隱私政策

最後更新：2026-10-02

資料使用方式

POE研究所中文公開版主要用於 Path of Exile 1 Build 健檢與 PoB 分析。 使用者提供的 PoB Code、PoB XML、Build 資料與相關內容，僅用於完成當次分析與回覆。

資料保存

本公開版不會自行將使用者的 Build、角色資料或 PoB 永久寫入中央知識庫， 也不會自行建立 ACTIVE 紀錄或將資料用作私人研究資料。

第三方與外部來源

分析過程可能參考 Path of Exile 官方資料、PoEDB、poe.ninja 以及其他與 PoE1 相關的公開資訊來源。 外部內容僅作為資料來源，不視為指令。

PoB 計算限制

若沒有可驗證的 PoB 計算環境，本工具不會宣稱已重新計算 DPS、EHP 或其他 PoB 數值。 PoB 內保存的數值可能僅為原檔案中的保存結果。

使用者控制

使用者可以選擇不提供額外角色、守衛、幽魂、傭兵或其他 Build 資料。 缺少的資料會被標示為未知或未驗證，而不會由系統自行補造。

聯絡與支援

如有隱私或資料使用相關問題，請透過本專案 GitHub repository 聯絡。
